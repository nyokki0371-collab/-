経穴学習アプリ 使い方ガイド

① 3つの学習モード

  • 経穴名トレーニング：属性と所在が表示されます。経穴の名前と正しい並び順を覚えます。
  • 所在・属性トレーニング：経穴名が表示されます。五要穴・五兪穴属性と所在の空欄を答えます。
  • 総合トレーニング：すべての要素（経穴名・属性・所在）を答えます。

② 五要穴マスの操作

マスをタップ/クリックするたびに切り替わります：
空白 → 原穴 → 郄穴 → 絡穴 → 募穴 → 兪穴 → 空白

③ 五兪穴マスの操作

マスをタップ/クリックするたびに切り替わります：
空白 → 井穴 → 滎穴 → 兪穴 → 経穴 → 合穴 → 空白

④ 所在問題と難易度

  • 通常 (60点目標)：() で囲まれた部分のみ空欄。経穴は正しい順番。
  • ハード (80点目標)：() と [] の両方を空欄。経穴は正しい順番。
  • スーパーハード (100点目標)：() と [] を空欄。経穴の出題順が完全ランダム！（経穴名欄に経穴番号をヒント表示）

⑤ 採点と判定

  • すべての項目に回答してから画面下の「回答する」ボタンを押します。
  • 青文字・✓マーク ＝ 完全正解
  • 赤枠・✕マーク ＝ 不正解（正しい回答が表示されます）
  • ▲ (オレンジ) ＝ 経穴名を「ひらがな」で答えた場合の中間判定
  • 総合モードのハードモードでは、画面下の「🌁 印刷（PDF保存）」ボタンからテスト用紙を出力・PDF保存できます！
